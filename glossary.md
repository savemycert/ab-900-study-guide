# AB-900 Glossary

192 AB-900 terms and services, each in one plain-English sentence.

[A](#a) · [B](#b) · [C](#c) · [D](#d) · [E](#e) · [F](#f) · [G](#g) · [I](#i) · [K](#k) · [L](#l) · [M](#m) · [O](#o) · [P](#p) · [R](#r) · [S](#s) · [T](#t) · [U](#u) · [V](#v) · [W](#w) · [Z](#z)

## A

- **Active assignment**: A PIM assignment that grants a role immediately without activation.
- **Active user**: A user who took an intentional Copilot action, such as submitting a prompt.
- **Activity explorer**: A Purview history of actions on labeled and sensitive content over about 30 days.
- **Add-on license**: A license layered on a base plan to add a capability, such as Microsoft 365 Copilot.
- **Admin role**: A set of management permissions, separate from a license, such as Exchange Administrator.
- **Advanced hunting**: KQL queries over up to 30 days of raw Defender data.
- **Agent**: A version of Copilot focused on one job, with saved instructions, knowledge sources and optional actions.
- **Agent and plugin access**: The setting that decides which publisher types agents can be installed from.
- **Agent Builder**: The lightweight agent creator inside the Microsoft 365 Copilot app and Teams.
- **Agent Registry**: The Microsoft 365 admin center inventory of all the organization's agents.
- **Agent sharing setting**: The setting that controls org-wide sharing of Agent Builder agents.
- **Aggregated alert**: A DLP alert raised when matches pass a count or volume threshold in a time window.
- **AI Administrator**: A role that can create billing policies and manage organizational prompts.
- **Allow web search in Copilot**: The cloud policy that controls whether Copilot grounds answers in the public web.
- **Analyst**: A built-in reasoning agent that analyzes raw data files with Python and shows its code.
- **Application object**: An app's global definition, shown in App registrations in its home tenant.
- **Archived team**: A team made read-only, with content kept and posting blocked.
- **Assessment**: A Compliance Manager grouping of a regulation's controls created from a regulatory template.
- **Assign new owner**: Transferring an agent to a new owner, removing the previous owner's access.
- **Assume breach**: The Zero Trust principle of limiting damage by segmenting, encrypting and detecting.
- **Authentication**: Proving who a user or app is.
- **Authentication context**: An Entra tag targeted by Conditional Access and applied to one site to require stronger sign-in.
- **Authorization**: Deciding what an authenticated identity may do.
- **Automatic attack disruption**: Defender XDR containment of compromised users and devices during an attack.

## B

- **Billing Administrator**: The role for purchases, subscriptions, billing and pay-as-you-go policies.
- **Billing policy**: The Microsoft 365 setting that links metered Copilot usage to an Azure subscription and resource group.
- **Block (agent)**: A lifecycle action that stops everyone using an agent indefinitely, keeping its configuration.
- **Block download policy**: A per-site setting allowing browser-only access with no download, print or sync.
- **Budget**: A billing policy amount that emails alerts at chosen percentages without stopping usage.

## C

- **Channel site**: The SharePoint site created automatically for a private or shared Teams channel.
- **Client-side auto-labeling**: Office apps recommending or applying a label while a user edits matching content.
- **Communication Compliance**: The Purview solution that flags inappropriate or sensitive message content for review.
- **Communication site**: A SharePoint site for publishing to a broad audience with few authors.
- **Compliance Manager**: The Purview tool that scores progress against regulations with assessments and improvement actions.
- **Compliance score**: A Compliance Manager percentage that rises as improvement actions are implemented and tested.
- **Conditional Access**: Entra ID policies that apply grant or session controls when sign-in conditions match; needs P1.
- **Connected experiences in Office**: The Cloud Policy setting whose disabling turns off scheduled prompts and other connected features.
- **Connected service**: A pay-as-you-go service, such as Copilot Chat or SharePoint agents, linked to a billing policy.
- **Container label**: A sensitivity label on a team, group or site that sets privacy, guest access and sharing.
- **Content marking**: Headers, footers and watermarks added by a sensitivity label.
- **Content search**: A Purview eDiscovery search that finds and exports emails, chats and files.
- **Contribute**: A SharePoint level that edits items but cannot create or delete lists and libraries.
- **Copilot Analytics**: Microsoft's set of Copilot measurement tools across the admin center and Viva Insights.
- **Copilot Chat**: The web-grounded Copilot chat included with Microsoft 365 work accounts.
- **Copilot connector**: A connector that indexes external content into Microsoft Graph with its access lists.
- **Copilot Dashboard**: The Viva Insights dashboard showing leaders Copilot readiness, adoption, impact and sentiment.
- **Copilot Frontier**: The setting that gives all users or chosen groups access to preview Copilot features; default No access.
- **Copilot image generation**: The setting that controls whether Copilot creates and edits images.
- **Copilot in Teams meetings policy**: The organizer's meeting policy setting with four values controlling Copilot and transcripts.
- **Copilot readiness report**: The admin center report used to plan who gets Copilot licenses next.
- **Copilot Search**: The Copilot experience for finding files and messages across Microsoft 365.
- **Copilot Studio**: The full maker tool for organization-wide agents with actions, workflows and external connectors.
- **Copilot Studio capacity**: Prepaid capacity that can pay for metered agent use instead of pay-as-you-go.
- **Custom agent**: An agent an organization builds for a repeated job with fixed instructions and scoped knowledge.

## D

- **Data access governance (DAG) report**: A SharePoint admin center report on site permissions, labels or recent sharing.
- **Data explorer**: A Purview snapshot of where classified items are, by location.
- **Data Explorer Content viewer**: A role group that can see the contents of items in Data explorer.
- **Data Explorer List viewer**: A role group that sees the list and locations of items, not their contents.
- **Data Lifecycle Management**: The Purview solution that retains content and deletes it when no longer needed.
- **Data Loss Prevention (DLP)**: The Purview solution that warns or blocks risky sharing of sensitive data in real time.
- **Data risk assessment**: A DSPM for AI scan for overshared content, by default weekly on the top 100 sites by usage.
- **Default label**: A label a policy applies automatically to unlabeled items in the apps.
- **Defender for Cloud Apps**: The Defender product that discovers cloud and AI apps and can block unsanctioned ones.
- **Delegated access**: Access to the Copilot Dashboard granted to someone who doesn't get it automatically.
- **Distribution group**: A mail-only group with static membership that cannot grant permissions.
- **DLP alert**: A notification that a DLP rule matched, best managed in the Defender portal.
- **Document fingerprinting**: A SIT option that recognises documents based on a standard template.
- **Domain verification**: Proving ownership of a custom domain by adding a tenant-specific TXT record at its DNS host.
- **DSPM for AI**: The Purview hub showing AI app usage and sensitive data in AI interactions, with one-click policies.
- **Dynamic distribution group**: A mail-only group whose membership Exchange calculates from recipient attributes.
- **Dynamic membership group**: An Entra group whose members are set by a rule on user attributes; needs P1.

## E

- **eDiscovery**: Purview tools that search for and hold content for legal cases.
- **eDiscovery Manager**: The role group that grants search, preview and export with least privilege.
- **Eligible assignment**: A PIM assignment that grants a role only after the user activates it.
- **Enabled user**: A user who holds a Copilot license.
- **Entra audit logs**: Records of directory changes, kept 7 days on Free and 30 days on P1 or P2.
- **Escalate for investigation**: A Communication Compliance action that opens an eDiscovery (Premium) case.
- **Everyone except external users (EEEU)**: A broad built-in group covering all internal users, a common oversharing cause.
- **Exact data match (EDM)**: Classification that checks values against an uploaded table of your real data.

## F

- **Full Access**: A shared mailbox permission to open and manage its items, without sending.

## G

- **Global Reader**: A role that can view every setting a Global Administrator can see without changing anything.
- **Grant control**: The part of a Conditional Access policy that blocks access or requires something, such as MFA.
- **Grounding**: Adding relevant retrieved content to a prompt before the model writes its answer.
- **Group-based licensing**: Assigning a license to a group so members gain or lose it automatically with membership.
- **Guest user**: An external person invited into the tenant who signs in with their own organization's account.

## I

- **ID Protection**: The Entra feature that detects risky users and risky sign-ins.
- **Identity Secure Score**: A percentage showing how closely identity settings follow Microsoft's recommendations.
- **Improvement action**: A recommended step that earns points toward a secure or compliance score.
- **Inactive site policy**: A SAM policy that asks owners to confirm inactive sites and archives or locks unconfirmed ones.
- **Incident**: A Defender XDR grouping of related alerts from several products into one attack story.
- **Information Protection**: The Purview solution that discovers, classifies and protects content with sensitivity labels.
- **Initial domain**: The tenant's onmicrosoft.com domain, which stays after custom domains are added.
- **Insider Risk Management**: The Purview solution that correlates risky user activities into scored alerts and cases.
- **Instructions**: The saved rules for an agent's tone, format and behaviour.

## K

- **Knowledge source**: The websites, sites, files or connectors an agent answers from.

## L

- **Label inheritance**: New Copilot content taking the highest-priority label among its labeled sources.
- **Label policy**: The policy that publishes sensitivity labels to users and sets defaults and mandatory labeling.
- **Least privilege access**: The Zero Trust principle of granting just enough access, just in time.
- **Legacy authentication**: Older protocols such as IMAP, POP and SMTP basic auth that cannot perform MFA.
- **License**: A subscription assignment that provisions Microsoft 365 services, such as a mailbox and Teams, for a user.
- **License Administrator**: The least-privileged role for assigning, removing and updating licenses.

## M

- **Mail-enabled security group**: A security group with an email address, usable for both mail and access.
- **Mandatory labeling**: A policy setting that makes users choose a label before saving or sending.
- **Meter**: An Azure measure of metered Copilot usage, such as Copilot Chat agents or SharePoint agents.
- **Metered agent**: An agent grounded in shared tenant data, billed per use for unlicensed users.
- **Microsoft 365 Copilot**: The add-on licensed AI assistant grounded in work data through Microsoft Graph and built into the apps.
- **Microsoft 365 Copilot (Basic)**: A tier giving some unlicensed users standard, non-priority Copilot in Word, Excel, PowerPoint and OneNote.
- **Microsoft 365 group**: A group with a shared inbox, calendar, SharePoint site and Planner that can become a team.
- **Microsoft Copilot experiences**: The retention location for Copilot prompts and responses.
- **Microsoft Copilot usage report**: The admin center report comparing enabled and active Copilot users by app.
- **Microsoft Cost Management**: The Azure tool that shows pay-as-you-go charges on the linked subscription.
- **Microsoft Defender XDR**: A unified suite that correlates Defender signals into incidents and coordinates response.
- **Microsoft Entra ID**: The cloud identity service that authenticates sign-ins and controls access to Microsoft 365.
- **Microsoft Graph**: The API layer over Microsoft 365 data that Copilot searches as the signed-in user.
- **Microsoft Purview**: Microsoft's family of data security, governance and compliance solutions.
- **Microsoft Purview Audit**: The unified audit log of user and admin activity across Microsoft 365.
- **Multifactor authentication (MFA)**: Sign-in using factors from at least two of know, have and are.

## O

- **Org settings**: Microsoft 365 admin center settings that apply to the whole organization, on the Services, Security & privacy and Organization profile tabs.
- **Organizational prompt**: An admin-published prompt shown to everyone, deleted permanently.
- **Oversharing**: Content shared more widely than it should be, which Copilot makes easier to find.

## P

- **Passkey (FIDO2)**: A cryptographic credential on a security key or device that will not sign in to the wrong site.
- **Password Administrator**: A role limited to resetting passwords for non-administrators and a few low-privilege roles.
- **Pay-as-you-go**: Billing for metered Copilot usage to an Azure subscription, with no seat cost.
- **Permission inheritance**: Libraries, folders and files taking their permissions from the site above them.
- **Permission level**: A named set of SharePoint permissions, such as Full Control, Edit, Contribute or Read.
- **Permission trimming**: Copilot using only content the signed-in user can at least view.
- **Phishing-resistant authentication**: Methods bound to the real sign-in site, such as passkeys, Windows Hello for Business and certificate-based authentication.
- **Policy ranking**: The order that decides which group-assigned Teams policy applies when a user is in several groups.
- **Policy tip**: A DLP notice shown to a user when an action matches a rule.
- **Power Platform admin center**: The admin center that reports operational insights for Copilot Studio agents.
- **Preinstall**: Installing an agent for chosen users as part of publishing.
- **Preservation Hold library**: The hidden SharePoint and OneDrive location keeping retained copies of deleted or edited files.
- **Principles of retention**: The rules that resolve conflicts, starting with retention wins over deletion.
- **Private channel**: A Teams channel limited to a subset of the team's members.
- **Privileged Identity Management (PIM)**: An Entra feature for just-in-time, time-bound, approval-based admin role access.
- **Pseudonymization**: Replacing usernames with generated identifiers, the Insider Risk Management default.
- **Publish to store**: The approval wizard that sets an agent's audience, preinstall, policy template and consent.
- **Purview browser extension**: The extension that lets Purview see third-party AI site activity in Chrome.

## R

- **Record**: An item locked by a retention label against editing and deletion.
- **Recoverable Items**: The mailbox folder where retained mailbox items are kept.
- **Remove message in Teams**: A Communication Compliance action that hides a message from chat participants.
- **Report-only mode**: A Conditional Access state that records a policy's result on real sign-ins without enforcing it.
- **Requests**: The agents page queue of submissions, pending updates and install requests awaiting an admin.
- **Researcher**: A built-in reasoning agent that produces structured, cited reports from work content and the web.
- **Resource mailbox**: A room or equipment mailbox used to book a place or an item.
- **Responsible AI principles**: Fairness, reliability and safety, privacy and security, inclusiveness, transparency and accountability.
- **Restricted access control**: A SAM setting that limits a site or OneDrive to members of up to 10 groups who also have permission.
- **Restricted Content Discovery**: A SAM setting that hides a site's content from Copilot and org-wide search without changing permissions.
- **Retention label**: A retention setting applied to individual items that can also declare records.
- **Retention policy**: A retention setting applied to whole locations.

## S

- **Safe Attachments**: A Defender for Office 365 feature that detonates attachments in a sandbox before delivery.
- **Safe Links**: A Defender for Office 365 feature that checks URLs at the time of click.
- **Saved prompt**: A private prompt kept for the user's own reuse.
- **Scheduled prompt**: A prompt that runs automatically at chosen times for the user who scheduled it.
- **Screen and camera sharing**: The Copilot vision setting, on by default.
- **Security defaults**: A free, all-or-nothing Entra ID baseline that requires MFA registration and blocks legacy authentication.
- **Self-service purchases**: The setting that lets users buy, only trial, or neither for Copilot products.
- **Semantic index**: The index Copilot uses to find content related to a prompt.
- **Semi-Annual Enterprise Channel**: The one Microsoft 365 Apps update channel without Copilot.
- **Send As**: A permission to send mail that appears to come only from another mailbox.
- **Send on Behalf**: A permission to send mail shown as one person on behalf of a mailbox.
- **Sensitive information type (SIT)**: A pattern-based definition of sensitive data such as a credit card number.
- **Sensitivity label**: A label that classifies content and can encrypt it, mark it or set container settings.
- **Service plan**: One service inside a license, such as Exchange Online or Planner, that can be turned off per assignment.
- **Service principal**: An app's local instance in a tenant, shown in Enterprise applications.
- **Service-side auto-labeling**: A policy that labels matching content in SharePoint, OneDrive and Exchange with no user involved.
- **Session control**: The part of a Conditional Access policy that limits a session after access is granted.
- **Shared channel**: A Teams channel that can include people outside the team or organization without guest accounts.
- **Shared mailbox**: A mailbox several people use, needing no license within 50 GB.
- **Shared prompt**: A prompt shared from Copilot Prompt Gallery with the members of one team.
- **Shared responsibility model**: The split in which Microsoft's controls count automatically and customers complete their own actions.
- **SharePoint Advanced Management (SAM)**: SharePoint governance features for oversharing and site sprawl, included when the tenant has at least one Microsoft 365 Copilot license.
- **SharePoint agent**: An agent that answers from one SharePoint site's content.
- **Sign-in risk**: The likelihood that a particular sign-in was not made by the account owner.
- **Single sign-on (SSO)**: Signing in once with one identity to reach many connected apps.
- **Site access review**: A request from an admin to a site's owners to review and fix its permissions.
- **Soft delete (agent)**: Deleting an agent so it can be restored for 30 days.
- **Starter prompt**: A suggested prompt configured inside an agent and shown only there.

## T

- **Temporary Access Pass (TAP)**: A time-limited admin-issued passcode used to onboard or recover and register a passwordless method.
- **Threat analytics**: Microsoft research reports in the Defender portal mapped to an organization's exposure.
- **Threat intelligence**: Knowledge about attackers' campaigns, tools and infrastructure used to improve protection.
- **Trainable classifier**: A machine-learning model that recognises a kind of document.

## U

- **Unified audit log**: The combined record of user and admin activity that activity explorer and DSPM for AI draw on.
- **Unsanctioned app**: An app tagged in Defender for Cloud Apps to be blocked on Defender for Endpoint devices.
- **Usage location**: The country or region set on a user that must exist before a license is assigned directly.
- **Usage rights**: The actions an encryption label permits, such as VIEW, EDIT, PRINT and EXTRACT.
- **User access (agents)**: The setting that decides which people can access and install agents.
- **User mailbox**: A licensed mailbox holding one person's mail, calendar and contacts.
- **User risk**: The likelihood that an account itself is compromised.

## V

- **Verify explicitly**: The Zero Trust principle of authenticating and authorizing every request on all available signals.

## W

- **What If tool**: A simulator that lists which Conditional Access policies would apply to a described sign-in.

## Z

- **Zero Trust**: A security model that never trusts a request by location and checks every request.
